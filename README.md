# mishrawrites.com

Personal site of Gaurav Mishra, served by GitHub Pages.

- `index.html`: the one-page site. Visitors pick who they are (founder, marketing head, HR) and the page adapts. Share persona links directly: `/?for=founder`, `/?for=marketing`, `/?for=talent`, optionally with `&co=CompanyName`.
- `monoblog/`: the blog. One folder per post.
- `Gaurav-Mishra-CV.pdf`: the CV. Source and rebuild steps in `_cv/`.
- `404.html`: sends old URLs (blog posts, case studies, about, work) to their new home.
- `_archive/`: the previous version of the site, kept in git. Folders starting with `_` are not published by GitHub Pages. To bring a page back, move it to the root.

Forms are delivered by Web3Forms to the account email. Analytics: GoatCounter (persona picks and case-study clicks are logged as events).
